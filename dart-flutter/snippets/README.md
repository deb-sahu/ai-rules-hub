# Dart/Flutter Code Snippets

This directory contains reusable code templates and snippets for common Dart/Flutter patterns.

## Available Snippets

### Widget Templates
- **File**: `widget-templates.dart`
- **Description**: StatelessWidget and StatefulWidget templates with const constructors

### Provider Pattern
- **File**: `provider-pattern.dart`
- **Description**: ChangeNotifier provider with loading and error states

### Async Builders
- **File**: `async-builders.dart`
- **Description**: FutureBuilder and StreamBuilder patterns with proper state handling

### Model Class
- **File**: `model-class.dart`
- **Description**: Model template with JSON serialization, copyWith, and equality

### API Service
- **File**: `api-service.dart`
- **Description**: HTTP service with error handling and type-safe responses

### Custom Hooks
- **File**: `custom-hooks.dart`
- **Description**: Examples of custom hooks using flutter_hooks

### Navigation
- **File**: `navigation-patterns.dart`
- **Description**: Named routes setup and navigation helper methods

### Form Handling
- **File**: `form-handling.dart`
- **Description**: Form validation patterns with TextEditingController

### Testing
- **File**: `widget-tests.dart`
- **Description**: Widget and unit test examples using flutter_test

## Usage

Copy and adapt these snippets to your project. Each snippet follows the coding standards defined in `rules.yml` and demonstrated in `styleguide.md`.
