# C#/.NET Code Snippets

This directory contains reusable code templates and snippets for common C#/.NET patterns.

## Available Snippets

### Service Pattern
- **File**: `service-pattern.cs`
- **Description**: Template for implementing a service class with dependency injection

### Repository Pattern
- **File**: `repository-pattern.cs`
- **Description**: Template for implementing a repository class

### API Controller
- **File**: `api-controller.cs`
- **Description**: RESTful API controller template with async actions

### Unit Test Template
- **File**: `unit-test-template.cs`
- **Description**: xUnit test class template with common patterns

### Extension Methods
- **File**: `extension-methods.cs`
- **Description**: Examples of useful extension methods

## Usage

Copy and adapt these snippets to your project. Each snippet follows the coding standards defined in `rules.yml` and demonstrated in `styleguide.md`.
