# Python Code Snippets

This directory contains reusable code templates and snippets for common Python patterns.

## Available Snippets

### Class Templates
- **File**: `class-templates.py`
- **Description**: Templates for different types of Python classes

### Async Patterns
- **File**: `async-patterns.py`
- **Description**: Common async/await patterns

### Decorators
- **File**: `decorators.py`
- **Description**: Useful decorator patterns

### Context Managers
- **File**: `context-managers.py`
- **Description**: Custom context manager examples

### Testing Fixtures
- **File**: `test-fixtures.py`
- **Description**: pytest fixture examples

## Usage

Copy and adapt these snippets to your project. Each snippet follows the coding standards defined in `rules.yml` and demonstrated in `styleguide.md`.
