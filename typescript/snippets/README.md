# TypeScript Code Snippets

This directory contains reusable code templates and snippets for common TypeScript patterns.

## Available Snippets

### API Service
- **File**: `api-service.ts`
- **Description**: Template for creating a type-safe API service

### Utility Functions
- **File**: `utility-functions.ts`
- **Description**: Common utility functions with proper typing

### Custom Types
- **File**: `custom-types.ts`
- **Description**: Examples of useful TypeScript types and interfaces

### Error Handling
- **File**: `error-handling.ts`
- **Description**: Custom error classes and error handling patterns

### Async Patterns
- **File**: `async-patterns.ts`
- **Description**: Common async/await patterns and utilities

## Usage

Copy and adapt these snippets to your project. Each snippet follows the coding standards defined in `rules.yml` and demonstrated in `styleguide.md`.
