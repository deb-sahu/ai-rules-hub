# SQL Code Snippets

This directory contains reusable SQL templates and snippets for common database patterns.

## Available Snippets

### Table Creation
- **File**: `table-templates.sql`
- **Description**: Templates for creating well-structured tables

### Stored Procedures
- **File**: `stored-procedure-templates.sql`
- **Description**: Common stored procedure patterns

### Query Patterns
- **File**: `query-patterns.sql`
- **Description**: Optimized query patterns for common scenarios

### Index Strategies
- **File**: `index-strategies.sql`
- **Description**: Index creation patterns for different use cases

### Migration Scripts
- **File**: `migration-templates.sql`
- **Description**: Safe database migration patterns

## Usage

Copy and adapt these snippets to your project. Each snippet follows the coding standards defined in `rules.yml` and demonstrated in `styleguide.md`.
