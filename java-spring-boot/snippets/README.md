# Java/Spring Boot Code Snippets

This directory contains reusable code templates and snippets for common Java/Spring Boot patterns.

## Available Snippets

### REST Controller
- **File**: `rest-controller.java`
- **Description**: Template for creating REST controllers with CRUD operations

### Service Layer
- **File**: `service-template.java`
- **Description**: Service class template with dependency injection and transactions

### JPA Entity
- **File**: `jpa-entity.java`
- **Description**: JPA entity template with common annotations and lifecycle callbacks

### Repository Interface
- **File**: `repository-interface.java`
- **Description**: JpaRepository template with custom query methods

### Exception Handling
- **File**: `exception-handling.java`
- **Description**: Global exception handler with @ControllerAdvice

### DTO Pattern
- **File**: `dto-pattern.java`
- **Description**: Data transfer object with builder pattern and validation

### Configuration
- **File**: `configuration.java`
- **Description**: Spring configuration class template with @ConfigurationProperties

### Testing
- **File**: `unit-tests.java`
- **Description**: Unit test examples using JUnit 5 and Mockito

## Usage

Copy and adapt these snippets to your project. Each snippet follows the coding standards defined in `rules.yml` and demonstrated in `styleguide.md`.
