# React Code Snippets

This directory contains reusable code templates and snippets for common React patterns.

## Available Snippets

### Custom Hooks
- **File**: `custom-hooks.tsx`
- **Description**: Examples of useful custom React hooks

### Component Templates
- **File**: `component-templates.tsx`
- **Description**: Templates for different component types

### Context Pattern
- **File**: `context-pattern.tsx`
- **Description**: Template for creating React Context with hooks

### Form Handling
- **File**: `form-handling.tsx`
- **Description**: Patterns for handling forms in React

### Higher-Order Components
- **File**: `higher-order-components.tsx`
- **Description**: Examples of HOC patterns

## Usage

Copy and adapt these snippets to your project. Each snippet follows the coding standards defined in `rules.yml` and demonstrated in `styleguide.md`.
